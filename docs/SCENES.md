# 場景目錄（Scene Catalog）— 主軸重設

地位：**本檔定義專案主軸**。雙縫實驗降格為 preset 之一（判別關 #5）。
主軸 = 可組合嘅光現象沙盒：任何光學場景皆可描述、可求解、可顯示、可判別。

## 1. 場景模型（Scene = 一等公民）
```
Scene {
  emitters:   [点源 | 線源 | 平面波 | 波包]      // 位置、頻率/λ、相位
  medium:     n(x,y,λ) 折射率場                  // 含色散＝棱鏡/彩虹
  obstacles:  任意形狀遮罩 mask(x,y)             // 牆、縫、透鏡輪廓、微粒
  forces:     [質量点 | 電荷点 | 自訂]            // 接 11 號 K 矩陣
  detectors:  [觀測線 | 觀測面 | 点探針]          // commit 發生處
}
```
求解器按模式揀：wave（Huygens/FDTD over n）、ray（幾何＋力）、particle（力驅動）、hybrid（導引）。
**所有顯示層（L0–L3）、通道（11）、投影（12）皆場景中立。**

## 5. 維度策略（四種維度，四種處理）

### 5.1 維度階梯 = 判別關 #14
同脈衝喺 D=1..4 傳播：尾跡有無＝Green 函數結構＝維度簽名。
H 須重現：奇數維鋭前、偶數維尾跡；力律組合若破壞此結構＝記敗。
效能帳：512 + 96² + 32³ + 16⁴ ≈ 108k 格/步，Rust 單執行緒可跑 60fps。

### 5.2 解說層（docent mode）
- 每面板掛註解字串（preset 檔自帶 `explain:` 欄）。
- 「點解」側欄：物理原因一句話（例：奇數維強 Huygens；偏振=spin-1 內部空間）。
- 開關制；預設開（博物館預設要有導覽）。

## 6. 環境網格與同時接納（Unity Criterion）— 方法論憲法

### 6.1 原則
同一條公式嘅證明 = **喺成個環境網格上一次性全部答啱**。
環境 Env = (preset, D, 參數域, 極限/邊界旗標)；每環境殺死/激活唔同變數
（接 12 號：變數失效係環境效應，唔係公式變更），故計算表現各異而公式同一。

### 6.2 誠實規則（防過拟合）
- 每候選公式只准**全局常數**（如 K 矩陣、耦合強度）一次性 fitting；
- 每格環境嘅參數照現實實驗規格抄錄，**禁止逐格調參**；
- 任何一格失敗 = 該公式全局記敗（可局部修復假說再重跑，但紀錄保留）。

### 6.3 統一矩陣（M-unity 顯示）
- 行 = 環境網格（14 關 × 維度/極限變體）
- 列 = 候選公式（各派系照 research 三問框架安裝：01/02/05/06/H-K…）
- 格 = 表現縮圖 + 對現實簽名 ✓/✗
- **一列全綠 = 該公式統一回答所有實驗**；改全局參數→全矩陣同動
  （「一個對象驅動所有表現」嘅直接畫面）。
- 現況預期：01 列綠頭兩行；05 列近全綠；H 列待跑＝本專案存在意義。

### 6.4 批次 runner
統一矩陣唔係實時算：離線 batch（formula × env）產 signature 快取，
M-unity 視圖讀快取；單格可點擊展開成即時互動場景。
