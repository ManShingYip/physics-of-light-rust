# 04 量子／光子說（Quantum / Photon）— Planck / Einstein

年代：1900（Planck 量子化）→ 1905（Einstein 光量子）→ 1923（Compton）
代表：Planck、Einstein、Compton

## 核心主張
光能量唔係連續，而係一份份：`E = hν`。吸收與發射以量子（光子）為單位發生。

## 三問框架
- 本體：能量量子（光子）
- 動力：自由傳播時仍用波（本派早期唔答動力學）；光子帶動量 `p = h/λ`
- 測量：吸收事件係離散嘅——一次一個量子

## 關鍵實驗／證據
- 黑體輻射譜（Planck 公式完美 fit）
- 光電效應：動能只隨頻率、存在閾值（Einstein 1905，1921 諾獎原因）
- Compton 散射（1923）：光子如粒子帶動量碰撞，波長偏移符 `p = h/λ`

## 數學骨架
`E = hν`、`p = h/λ`；吸收率離散化。

## 對應本專案
- 安裝槽：L3 結果層——commits 打點正係「吸收事件離散化」嘅畫面；直方圖累積 = 單光子實驗嘅時間軸
- 展示價值：開 accum、逐粒出點、條紋慢慢浮現，就係呢派嘅歷史重演
