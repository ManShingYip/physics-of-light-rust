# 光之調查（Research Index）

目的：系統性整理歷來關於光嘅學術觀點與理論派系，
並將每個派系**操作化**為本專案引擎嘅一個可安裝模式——
調查唔係死資料，而係「邊個派系喺畫面上長咩樣」嘅對照表。

## 方法論：三問框架
任何光理論都可以拆成三條答案，呢三條直接映射入引擎槽位：
1. **本體論**：光係乜實體？（粒子／場／激發／資訊）→ 引擎實體槽
2. **動力學**：佢點郁？（力律／波動方程／測地線／路徑和）→ 引擎更新槽
3. **測量論**：觀測發生乜事？（坍縮／採樣／無事發生）→ commits 規則槽

答齊三條，該派系就可以被「安裝」並顯示。答唔齊嘅位置就係佢嘅開放問題。

## 使用規則
- 主軸唔喺呢度：場景沙盒與 13 判別關見 `docs/SCENES.md`；本 folder 只提供派系觀點與投影/組合框架。
- 新增派系：照三問框架開新檔，編號順延，更新本表。
- 每檔結尾必有「對應本專案」段：寫明裝進邊個槽、畫面預期長咩樣。
- 爭議唔裁决：並列陳述，交畀 M-duel 畫面去對決。
