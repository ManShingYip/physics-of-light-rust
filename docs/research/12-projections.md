# 12 投影框架：空間圖冊與不完全表現嘅膠合（Projection Atlas）

地位：11 號檔（動力學面）之補完——本檔處理**運動學面**：
同一個 X 喺唔同空間嘅投影。

## 12.1 假說 P
X（未名之光）可能有條**通用公式**；
但我哋永遠只喺某個空間（數學的或物理的）見到佢嘅**投影**：
- 某空間入面某個變數**突然失效**（退化、消失、無定義）→ 該空間只給不完全表現；
- 可能**所有**空間都係不完全表現；
- 但各空間嘅不完全表現**膠合**起來 = 完整公式。

## 12.2 承載呢個想法嘅現成數學
| 數學結構 | 對應概念 |
|---|---|
| 流形圖冊（atlas）＋轉換函數 | 空間集合＋空間之間嘅翻譯規則 |
| 層（sheaf）＋膠合條件 | 局部截面唯一決定全局截面；膠合失敗＝obstruction |
| 層上同調（obstruction class） | 「點解單空間永遠睇唔全」嘅可計算度量 |
| 退化極限（ħ→0、m→0） | 「變數突然失效」嘅標準例子：量子項／質量項消失 |
| 互補性（x-chart vs k-chart） | 物理學已有嘅圖冊：傅立葉變換＝轉換函數 |
| 全像（boundary chart） | 09 派＝另一張 chart，唔係另一種本體 |

結論：假說 P 唔係新數學，而係**將已有數學升格為本體論立場**：
X = 全局截面；實驗/畫面 = 局部截面。

## 12.3 投影表（M-projection 面板）
| 面板 | 空間 | 見到乜 | 失效變數（徽章） |
|---|---|---|---|
| P1 | 位置空間 x | 波紋、干涉、牆 | 動量細節 Δk |
| P2 | 動量空間 k（FFT） | 雙峰＝縫距簽名 | 位置 Δx |
| P3 | 相空間（Wigner） | 波＋粒子同框嘅準機率 | 正定性（負值區＝失效閃光） |
| P4 | 路徑空間 | 路徑密度熱圖 | 單一路徑身份 |
| P5 | 資訊空間 | commits 直方圖、熵 | 測量前場態 |

每面板角落掛**失效變數徽章**：明示「呢個空間殺死咗乜」——
「變數突然失效」由隱喻變做畫面上嘅文字。

## 12.4 膠合面板（Gluing Panel）
1. 還原測試：由 P2 逆傅立葉還原 ψ，與 P1 比對 → mismatch 度量；
   由任意**單**面板還原必失敗、由**組合**還原成功 → 「組合先完整」嘅直接畫面。
2. **Obstruction 閃光**：膠合條件失敗處（Wigner 負值區、還原 mismatch > ε、
   面板間 dominance 序列矛盾）以閃光標記。
3. 閃光 = 新物理候選人 → 寫入 11.5 反推循環嘅「待找」清單。

## 12.5 引擎介面
```rust
pub struct XState {          // 空間中立：無首選表示
    pub psi: Field, pub particles: Vec<Particle>, pub k: Coupling,
}
pub trait Projection {
    fn project(&self, s: &XState) -> View;      // 局部截面
    fn lost_vars(&self) -> &'static [Var];      // 失效變數徽章
    fn reconstruct(&self, views: &[View]) -> Option<XState>; // 膠合
}
pub fn obstruction(views: &[View]) -> Vec<Hotspot>; // 閃光位
```
- FFT：96×96 夠細，naive O(n²) 或 radix-2 皆可，Rust 側算。
- Wigner：取觀測線附近 1D slice 即可出負值示範。

## 12.6 反推含義
- 若**所有**投影都喺同一變數退化 → 該變數可能喺現實根本唔存在
  （X 嘅自由度比我哋假設少）→ 強預測。
- 若某兩投影膠合永遠失敗 → 轉換函數寫錯（數學錯）或 X 有隱藏自由度（物理新）。
  區分方法：換第三投影做中介，睇三角膠合邊邊失敗。

## 12.7 與 11 號檔關係
- 11 = 動力學面（通道、K 矩陣）；12 = 運動學面（投影、膠合）。
- K 矩陣住喺 XState 入面：每個投影睇到 K 嘅不同切片。
- M-facets（11）與 M-projection（12）可疊加：面板內再染通道色。
