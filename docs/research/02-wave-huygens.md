# 02 波動說（Wave Theory）— Huygens / Young / Fresnel

年代：1678（Huygens）→ 1801（Young 雙縫）→ 1818（Fresnel 衍射數學）
代表：Huygens、Young、Fresnel

## 核心主張
光係介質（以太）中嘅波；波前每點係新子波源（Huygens 原理），子波疊加決定傳播。

## 三問框架
- 本體：場（介質位移）
- 動力：波動方程；Huygens–Fresnel 疊加積分
- 測量：無坍縮——強度即能量分佈，探測器只係吸收

## 關鍵實驗／證據
- Young 雙縫干涉條紋（1801）
- Poisson 亮斑（1818）：Poisson 用 Fresnel 理論導出「圓影中心應有亮點」想反駁，實驗真係見到——波動說大勝
- 光喺水行得慢（與 01 預測相反）

## 致命傷
- 以太：邁克耳遜–莫雷（1887）搵唔到
- 光電效應：能量與強度無關、與頻率有關——波解釋唔到

## 數學骨架
`u(x,t)` 滿足 `∂²u/∂t² = c²∇²u`；雙縫 = 兩子波源疊加 `u = u1 + u2`，強度 `I = |u1+u2|²` 出條紋。

## 對應本專案
- 安裝槽：現狀 ghost 場層（M-wave）；`init_double_slit` 就係 Huygens 構造嘅直接實現（牆右兩柱面波疊加）
- 展示價值：L-ghost 彩色波紋 = 子波干涉圖
- 與假說 H 關係：H 嘅波場層借用佢嘅數學做「力嘅媒介」，但本體改做力+粒子
