# 09 資訊／全像觀點（Information / Holographic）— Bekenstein / 't Hooft / Susskind / Wheeler

年代：1972（Bekenstein 黑洞熵）→ 1990s（'t Hooft、Susskind 全像原理）；Wheeler「it from bit」
代表：Bekenstein、't Hooft、Susskind、Wheeler

## 核心主張
物理嘅基本貨幣係**資訊**而非物質或場：
- 有限區域可容納嘅資訊有上限（Bekenstein bound：熵 ∝ 表面積而非體積）
- 全像原理：體積內嘅物理 = 邊界上嘅低維理論嘅投影
- Wheeler：每個「it」都源自「bit」——提問（測量）創造事實

## 三問框架
- 本體：位元／熵／糾纏結構
- 動力：資訊守恆與演化（酉＝資訊唔丟）；AdS/CFT 為嚴格例子
- 測量：提問即抽取位元——**觀測 = 讀取**，與本專案前端哲學同構

## 關鍵實驗／證據
- 黑洞熱力學四定律、Hawking 輻射（理論）
- AdS/CFT 對偶（數學證據級）
- 實驗層面仍間接（熵界未被違反）
