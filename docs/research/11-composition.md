# 11 組合框架：面合成器與耦合矩陣（Facet Compositor）

地位：調查 folder 壓軸檔。回答「光係未有名字嘅東西、各派只摸到一面，點組合？」

## 11.1 問題陳述
光可能係人類語言仍未命名嘅實體 X。
01–09 各派唔係互相矛盾嘅完整理論，而係 **X 嘅不同投影面**。
組合嘅目標唔係裁决邊派啱，而係**同時顯示所有面**，
令面與面之間嘅**不變量**（即 X 本身）有機會浮現。

## 11.2 組合原則：通道疊加，唔係理論選擇
每派系貢獻一條**交互通道**（channel），全部同時在場：
| 通道 | 來源派系 | 內容 | 現實已測對應 |
|---|---|---|---|
| C_guid 導引 | 06 | v ∝ ∇phase(ψ) | 單粒子干涉統計 |
| C_geo 幾何 | 08 | 折射率 n=1+Φ 彎波前 | 重力 lensing（1919✓） |
| C_em 電磁 | 03 | 電荷區相位/力耦合 | AB 效應、折射（✓） |
| C_med 介質 | 02/03 | 介質梯度作力（折射即力） | Snell（✓） |
| C_path 路徑 | 07 | 路徑加權作採樣先驗 | 雙縫統計（✓） |
| C_bound 邊界 | 01/02 | 牆短程排斥 | 反射/影（✓） |
| C_read 讀取 | 05/09 | commit 規則（Born 或力觸發） | 探測統計（✓） |

淨效應 = Σ 通道貢獻；畫面用**通道染色**顯示每刻邊條通道主導。

## 11.3 耦合矩陣 K：「部份正確」嘅操作化
`K[i][j]` = 通道 i 與 j（或與物質/任何嘢）反應強度。
- 假說 H「部份正確」= K 中**光力行**某啲格非零。
- 已知非零格 = 已驗證面；**未知格 = 預測面**。
- 「同任何嘢反應」= K 留開放列（C_X 槽），新物質/新場加入即有新格。
- UI：K 矩陣熱力圖面板 + 每格滑桿；拖一格，畫面即時變。

## 11.4 展示模式 M-facets
1. 尾跡通道染色（dominance 升級版）：一條尾跡多色段 = 光沿途被多通道搶奪。
2. K 熱力圖面板：實時顯示邊格在作用。
3. 每通道貢獻弧線圖：淨力分解成各通道向量，箭頭疊加可見。
4. 關掉任何通道 = 「如果 X 面唔存在，宇宙長咩樣」嘅反事實視圖。

## 11.5 反推循環（sim → 現實）
1. sim 以某 K 配置跑出 **signature**：條紋偏移量、偏折角、直方圖相關係數、dominance 序列。
2. 對照**現實實驗目錄**（EXPERIMENTS.md 兩欄表）：
   | signature | 現實對應實驗 | 狀態 |
   |---|---|---|
   | 星旁偏折 2×Newton | Eddington 1919 | 已測✓ |
   | 環繞電荷條紋平移 | AB 效應 | 已測✓ |
   | 光束互彎 | 光子-光子散射 | 極弱/高能先測 |
   | （sim 新 signature） | ？ | **待找** |
3. 狀態=待找 嘅 signature = **去現實邊度搵嘅清單**：
   反推所需實驗幾何、量級、干擾源，寫入該行。
4. 現實測到/測唔到 → 回寫 K 格（非零/上限/否證）→ sim 更新 → 循環。

## 11.6 代碼介面（引擎槽位）
```rust
pub struct Channel { pub law: Box<dyn Force>, pub hue: [f32;3], pub on: bool }
pub struct Coupling { pub k: [[f32; N]; N] }   // N = 通道數 + 開放槽
net_force(p) = Σ_i on_i · ( Σ_j k[i][j] · mix(law_i, law_j) ) + base_i
signature(frame) -> Signature { fringe_shift, deflection, hist_corr, dominance_seq }
```
- `signature()` 係反推循環嘅起點：每幀可提取、可記錄、可匯出。
- C_read 獨立於力通道：測量規則可換（Born / 力觸發），用嚟測試 05 vs H。

## 11.7 哲學備註
- X（光本身）= 所有通道同時顯示時嘅**不變量**；代碼唔命名 X，只顯示面。
- 「未有名字」唔係缺陷：命名會過早坍縮假說空間。UI 文案稱之為「X / 未名」。
- 本框架自反：框架本身都係一面，隨時可被新通道取代。
