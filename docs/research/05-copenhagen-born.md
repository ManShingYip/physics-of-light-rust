# 05 哥本哈根／波粒二象性（Copenhagen）— Bohr / Born / Heisenberg

年代：1925–1927
代表：Bohr、Born、Heisenberg、Jordan

## 核心主張
光（與一切量子物）具互補性：波與粒子係同一實體嘅兩面，視實驗安排顯現。
`ψ` 係機率幅，`|ψ|²` 係機率；測量令疊加坍縮為本徵結果。

## 三問框架
- 本體：機率幅場 ψ（非物質波、非粒子流）
- 動力：酉演化（Schrödinger／波動光學等效）
- 測量：Born 規則採樣＋坍縮——**測量係基本公設，唔再解釋**

## 關鍵實驗／證據
- 全套：雙縫、單光子干涉、which-way 實驗（觀測即抹殺條紋）
- 統計預測無一失手

## 致命傷（哲學層）
- 測量問題：坍縮乜時刻發生？邊個算觀測者？

## 數學骨架
`iħ ∂ψ/∂t = Ĥψ`；測量得 `a` 嘅機率 `= |⟨a|ψ⟩|²`。
