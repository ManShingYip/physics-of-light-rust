# 08 幾何／相對論觀點（Geometric / Relativistic）— Einstein

年代：1905（狹義：光速不變）→ 1915（廣義：零測地線）
代表：Einstein、Eddington

## 核心主張
光無質量但行時空最直嘅路：零測地線（ds²=0）。
重力唔係拉光，而係**彎時空**，光照直行情願彎咗嘅路。

## 三問框架
- 本體：時空幾何中嘅零曲線
- 動力：測地線方程；折射率類比 `n(x) = 1 - 2Φ/c²`
- 測量：無特別——幾何決定一切

## 關鍵實驗／證據
- 1919 日蝕：星光偏折角度符廣義預測（Newton 值嘅兩倍）
- 重力透鏡、Shapiro 延遲、重力紅移、LIGO 引力波（光做探尺）

## 致命傷
- 宏觀幾何理論：唔答微觀干涉／單光子問題

## 數學骨架
`d²x^μ/dλ² + Γ^μ_{αβ} dx^α/dλ dx^β/dλ = 0`，限 `ds² = 0`。

## 對應本專案
- 安裝槽：F_G（平方反比井）＋M4 力—力交互：重力井改波場折射率
  `n(x) = 1 + Φ_G(x)` → 波前彎 → 條紋彎（lensing 入畫面）
- 展示價值：拖曳質量點，干涉紋即時扭曲——「時空彎曲」嘅玩具版
- 與假說 H 關係：H 喺宇宙視圖入面畀重力平等席位；lensing 正係力與力交互嘅示範
